# IT3130 Git Basics Lab

## Purpose
This repository demonstrates a basic Git workflow for IT3130.

## Files
- HelloWorld.html - a small web page used to practise version control
- README.md - project documentation

## Commands practised
git init, git status, git add, git diff, git commit, git log, git remote, git push
## What I learned

I learned that the staging area prepares changes before they are committed to the local repository. Commits record meaningful changes in the project history, while a remote repository allows the local project to be shared and synchronized with GitHub.
